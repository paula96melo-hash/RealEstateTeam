# Follow-up drafting

**Before drafting:** confirm channel is allowed (consent-dnc-verification) and note the contact's request/source. Use only information the contact provided; never infer protected traits.

**Templates (adapt; keep human, specific, short):**
- New online lead (≤ 5 min): "Hi [First Name], this is [Agent Name] with [Brokerage Name]. I saw you asked about [property/guide]. Want me to send [specific next step]? Reply STOP to opt out."
- Open house same-day: thanks + property fact sheet + "What would make the next one a perfect fit?" (fit = features/price, not neighbors)
- Open house next-day call script: 3 questions (timeline, must-haves, financing) → offer search setup → explain buyer agreement before touring
- Sphere check-in: personal note + one useful local item (ZIP stat, event) — no hard ask
- Past client anniversary: equity snapshot (cited), homestead/Amendment 3 reminder (no tax advice), insurance renewal tip
- Partner thank-you: gratitude + relevant market insight; never offer anything of value for referrals (RESPA)

**Output:** draft text per channel + why/when to send + consent check status. Save to `drafts/approval-queue/`. The human edits and sends.
