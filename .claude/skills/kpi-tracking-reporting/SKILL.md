# KPI tracking & reporting

**Scorecard (docs/03 §4, docs/07 §7):**
| Stage | Metric | Weekly target (new agent starting point) |
|---|---|---|
| Activity | conversations, SOI touches (50), open houses (2), content pieces (4–5), partner meetings (1) | |
| Lead | new leads by source, cost per lead | |
| Contact | median speed to first contact (< 5 min), contact rate | |
| Appointment | appointments set/held, buyer agreements, listing presentations | |
| Close | pending, closed, GCI, cost per closing by source | |

**Weekly review (30–45 min):** every new lead contacted? every A-lead has a next task? overdue tasks cleared? source report → which produced appointments?
**Monthly review:** funnel conversion by source, spend vs. budget, content → lead attribution, 90-day pipeline projection, recommendation (keep/stop/scale) per channel.

**Rules:** data comes from what the human exports (CRM, ads, analytics) — you never log in. Report small numbers honestly (n is small for a new agent; avoid over-reading). Attribute with tags, not guesses. Segment reports by source and needs-based segment only.

**Output:** scorecard table, 3 insights, 3 actions, open questions.
