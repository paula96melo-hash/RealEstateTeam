# Approval queue submission

Nothing leaves the team without a human. Package every outward-facing item (post, email, text, ad, flyer, script, event plan, outreach message, web page) like this.

**File:** `drafts/approval-queue/YYYY-MM-DD-<agent>-<short-slug>.md`

```markdown
# [Title]
- Status: PENDING COMPLIANCE REVIEW  | PENDING HUMAN APPROVAL | REVISE
- Drafted by: [agent name]   Date: [YYYY-MM-DD]
- Channel: [Instagram / email / SMS / Meta ad / print / event / web]
- Audience (needs-based, no protected characteristics): [...]
- Purpose & call to action: [...]
- Consent required? [yes/no — if yes, consent basis and DNC check owner]
- Sources: [docs §, URLs, dates]

## Draft
[the exact copy / asset spec]

## Compliance checklist (docs/05 §8)
[ ] brokerage name  [ ] licensee identified  [ ] no misleading claims  [ ] fair housing
[ ] EHO  [ ] ad special category  [ ] REALTOR® usage  [ ] permissions  [ ] AI/staging disclosure
[ ] consent/DNC/8am–8pm/≤3 calls  [ ] CAN-SPAM  [ ] RESPA

## Reviewer notes
[compliance-reviewer / consent-privacy-advisor findings]

## Human decision
[ ] Approved   [ ] Rejected   [ ] Revise — notes:
```

Rules:
- Leave the "Human decision" box unchecked. Only a human ticks it; never mark your own work approved.
- Use placeholders like `[Brokerage Name]` and `[Agent Name]` until the human supplies them.
- If you cannot write files, return the same block in your answer.
