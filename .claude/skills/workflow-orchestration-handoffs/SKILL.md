# Workflow orchestration & handoffs

**1. Frame** — restate the question, the decision it supports, constraints (budget, timeline, segment), and what "done" looks like.

**2. Pick experts** — smallest set that covers the question (usually 2–5):
| If the question involves… | Bring in |
|---|---|
| prices, trends, ZIPs | market-analyst |
| who to target, personas | segmentation-strategist |
| niche, competitors, brokerage choice | competitive-positioning-strategist |
| condos, assessments, SIRS | condo-due-diligence-specialist |
| rates, insurance, taxes, flood | housing-finance-advisor |
| where leads come from, what to buy/test | lead-generation-researcher |
| writing any copy | content-outreach-writer |
| social plan/posts | social-media-manager |
| video/YouTube | video-youtube-producer |
| website, SEO, Google Business Profile | seo-website-specialist |
| paid ads | paid-ads-specialist |
| events | events-scout |
| referral partners, co-marketing | partner-network-builder |
| CRM, follow-up | crm-follow-up-manager |
| tool stack, integrations | marketing-ops-architect |
| metrics, results | performance-analyst |
| money, runway, spend | budget-analyst |
| rule changes | regulatory-watch |
| **anything outward-facing** | **compliance-reviewer (always last before human)** |
| **any call/text/email/contact data** | **consent-privacy-advisor** |

**3. Brief each expert** — goal, specific sub-question, relevant `docs/` sections, inputs from other experts, required output format, deadline in turns. Experts don't see your conversation; briefs must be self-contained.

**4. Sequence** — run independent experts in parallel; run dependent ones after (e.g., segmentation → writer → compliance). Compliance review comes after drafts exist.

**5. Track** — a status table: task · expert · status · output location.
