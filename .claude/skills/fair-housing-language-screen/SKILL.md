# Fair housing language screen

**Protected classes for WPB marketing:** race, color, religion, sex, national origin, familial status (incl. pregnancy), disability (federal + Florida) **plus** age, marital status, sexual orientation, gender identity or expression (Palm Beach County ordinance). Source-of-income status in PBC is unverified — treat cautiously.

**Red-flag words/phrases → rewrite**
| Avoid | Use instead |
|---|---|
| perfect for families / family neighborhood / kid-friendly | 4 bedrooms; fenced yard; 0.3 mi to [park] |
| great for young professionals / singles / couples / retirees | 1BR near Brightline station; low-maintenance condo |
| mature/adult community (non-HOPA) | describe amenities only; "55+" only if HOPA-qualified |
| exclusive / private / safe / quiet / up-and-coming / desirable area | specific facts: gated entry, cul-de-sac, lot size |
| walking distance to [church/synagogue/mosque] as a selling point | distances to named general amenities, or omit |
| great schools / top-rated school district | "School assignment: see SDPBC boundary locator" |
| able-bodied, no wheelchairs, must climb stairs, ideal for active people | "second-floor unit; no elevator" (fact) |
| English-speaking, ethnic/national descriptors, "bilingual neighborhood" | omit |
| master bedroom (preferred style) | primary bedroom |
| no kids / adults only (non-HOPA) | omit |

**Also check:** images (diverse, not one demographic repeatedly), video voiceover and on-screen text, hashtags, alt text, AI-generated copy (often says "growing family"), ad targeting choices (see compliant-ad-targeting), steering in suggested replies ("you'd fit in better in…"), blockbusting (claims about who is moving in).

**Output:** PASS / REVISE / ESCALATE, each issue with quote → why → rewrite. Include Equal Housing Opportunity statement reminder for ads, websites, and print.
